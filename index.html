The tools

Three add-ins under the Exstream Pro line, each aimed at a different part of the Revit workflow.

CG

CG Manager

Keeps families, groups, and shared content organized and consistent across a Revit project, instead of scattered across browsers and schedules.

  • Centralized dashboard of every family, group, and shared component in the model
  • Search and filter content by category, family, or type project-wide
  • Batch rename, reload, or replace families without touching each instance
  • Flags duplicate or near-duplicate families for cleanup
  • Tracks shared content usage across linked models
  • One-click sync against your shared content library
Ex

Export Tool

Batch-exports sheets, views, and schedules out of Revit in one pass, instead of exporting them one at a time.

  • Select multiple sheets, views, or schedules and export together
  • One dialog for PDF, DWG, IFC, and image exports
  • Save and reuse export presets for recurring hand-off packages
  • Automatic file naming from sheet number, view name, or revision
  • Progress and log tracking for large batch runs
  • Works with existing sheet sets and view templates
Cl

Cleanup Toolkit

Finds and clears unused families, stray elements, and easy-to-fix warnings, so models stay lean before they're shared or archived.

  • One-click purge of unused families, materials, line styles, and view templates
  • Warning browser that groups and prioritizes issues for faster triage
  • Detects orphaned or unplaced elements
  • Model health summary — file size, element counts, warning counts
  • Preview mode shows what will be removed before you commit
  • Run on demand or as part of a regular maintenance pass
